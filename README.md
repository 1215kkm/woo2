# 우편지 포트폴리오

`npm run dev` 후 http://localhost:4173 접속. index.html을 직접 열어도 작동합니다.

반응형 정적 사이트입니다. 작업물 필터, 더 보기, 상세페이지 전체 길이 모달, 원본 링크, 키보드 닫기를 제공합니다.

새 상세페이지: assets/moon-buddy.png, assets/paw-go.png. 내장 이미지 생성 도구로 제작한 가상 제품 디자인입니다. 이미지 속 사양·일정·혜택은 예시이며 검증된 실상품 정보가 아닙니다.

생성 프롬프트 요약: MOON BUDDY — 보라색 오리지널 캐릭터 조명, 밤의 사용 장면·디테일·선물·런칭 혜택을 연결한 한국어 커머스 상세페이지. PAW & GO — 골든리트리버와 푸들이 등장하는 오렌지/세이지 산책 키트, 소재·사용 장면·세트 혜택을 연결한 한국어 상세페이지.

마케팅: @haileyselect는 사용자가 운영 사실을 제공한 계정입니다. 공개 게시물과 인사이트 접근에 실패해 실제 성과를 기재하지 않았습니다. 실험과 KPI는 제안이며 실제 실행 이력과 구분합니다. 실제 게시물, 기간, 인사이트 수치가 제공되면 index.html의 마케팅 영역을 업데이트하세요.

폴더에서 별도 팝업 파일은 확인되지 않았습니다. 배너는 23개 모두 assets/catalog.js에 연결했습니다. 폰트는 Google Fonts를 사용하며 네트워크 불가 시 시스템 글꼴로 표시됩니다.
