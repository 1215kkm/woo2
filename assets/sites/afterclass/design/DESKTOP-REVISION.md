# PC 재설계와 상세 이미지 비율 복구

2026-09-17 / 사용자 후속 지시

## 변경

- 사진 시트의 각 상품은 정사각형이다. 기존 모바일 282px 고정 높이와 PC의 1:1.08 박스가 이미지를 압축/확대했다. 최종 CSS를 `height:auto; aspect-ratio:1 / 1; background-size:200% 200%`로 통일했다. 393px 모바일 사진도 393×393이다.
- 모바일 홈·목록 및 내비게이션은 유지. 상세는 복구된 사진 높이만큼 아래 정보가 자연스럽게 밀리며 하단 선택 버튼은 유지된다.
- PC 홈: 넓은 캠페인 이미지, 5:7 텍스트/이미지 그리드, 68–118px 제목, 독립적인 컬렉션/스토리 링크.
- PC 목록: 168px 사이드바 + 상품 3열. 마지막 행의 2칸을 착장 노트로 활용. 상품 사진은 정사각형.
- PC 상세: 약 1.3:0.9 사진/구매 정보 비율. 우측에 S/M, 수량, 합계, 담기 버튼을 직접 제공. 긴 설명과 착장 콘텐츠는 아래 전체 폭에 배치.
- 공통 PC 최대 폭·헤더·타이포·여백 정리. 701–1050px에는 2열 목록과 축소된 캠페인/헤더 적용.
