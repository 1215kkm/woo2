# 2단계 디자인 정제

기존 AFTER CLASS의 크림·잉크·코발트, Archivo/Pretendard, 방과 후 캠페인을 유지했다. archive-v1은 수정 전 코드이며 exports의 mobile-/pc- 이미지는 1단계 기록이다.

## 변경 원리
- 홈의 큰 타이포, 얇은 구분선, 사진 캡션을 공통 언어로 적용. 둥근 카드 대신 여백과 행 구조로 구분.
- 홈: 큰 브랜드 문장 → 캠페인 사진/행동 → 카테고리. 목록: 상품 2개 다음 착장 노트로 탐색 리듬 추가.
- 상세: 제품 사진 → 이름/가격 → 단일 색상 → 사이즈 선택 → 장바구니. 소재/배송/후기는 아코디언. 옵션 시트는 선택 전 담기 비활성, 선택 후 수량·합계 표시.
- 공통 헤더·아이콘·하단 탐색·48px 주요 행동·24px 모바일 여백. 모션 160~180ms, reduced-motion 지원.
- 장바구니는 선택한 상품·사이즈·수량을 세션에 유지. 빈 결과·연결 오류·미선택 상태를 구체적인 한국어로 안내.

## 실제 확인
PowerTerminal Chrome에서 홈/목록/상세/선택 4개 × 320,393,430,768,1440px = 20개 조합 가로 넘침 0. 393px 핵심 4화면 이미지 로드 확인. 선택 전 비활성, S 선택 후 활성/요약 동기화, 수량 2개 합계 64,000원, 니트 2개 필터, 30,000원 이하 빈 결과 확인. JS 문법 검사 통과.

## 후속 연결
카페24 모듈·실제 재고/소재/치수/배송 정책·회원·주문·결제는 다음 단계. 가짜 후기/별점 추가 없음. 상세 두 번째 사진은 공용 브랜드 착장 참고 사진. 실제 기기/Safari/보조기술 검수는 미실시. 실사 목업은 AI 이미지이며 정확한 한국어/간격의 기준은 HTML과 브라우저 캡처다.
