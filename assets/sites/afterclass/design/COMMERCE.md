# 쇼핑 서비스 화면 확장

- design/commerce.js, commerce.css: 기존 크림·코발트·에디토리얼 디자인을 공유하는 반응형 서비스 화면.
- 고객센터 공지 목록/본문, FAQ, 문의 작성, 후기 빈 목록/작성, 이벤트 목록/상세, 쿠폰 받기, 주문서, 주문 완료, 주문내역/상세 추가.
- 장바구니: 여러 상품/옵션 누적, 동일 옵션 수량 합산, 개별/전체 선택, 수량 변경, 삭제, 빈 상태.
- 쿠폰: 세션 내 발급과 주문 할인 계산. 시안 조건 3만 원 이상 10%, 최대 5천 원. 배송비는 5만 원 미만 3천 원.
- 주문서: 필수 배송 정보, 연락처 형식, 동의 체크, 쿠폰 선택. 실제 결제 없음. 개인정보는 저장·전송하지 않음.
- 시안 주문 상품과 금액만 sessionStorage에 저장. 선택 상품만 주문 후 장바구니에서 제거. 고객센터 작성 내용은 저장·전송하지 않음.
- 메인 하단과 마이페이지에 서비스 링크 추가. commerce-review.html에서 각 화면 진입 가능.
- scripts/check-commerce.cjs 36개 DOM/동작 검사 통과. 실제 브라우저 렌더링·모바일 키보드 검수 및 고해상도 캡처는 미실시.
- 실제 카페24 회원/쿠폰/게시판/주문/배송/결제 연동, 실상품 배송 정책 및 주문 취소·교환·반품 기능은 후속 작업.
